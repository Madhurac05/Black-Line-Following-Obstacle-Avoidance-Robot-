# Black-Line-Following-Obstacle-Avoidance-Robot-
Designed and developed an autonomous robot using microcontrollers, IR sensors, and ultrasonic sensors for real-time navigation. Implemented algorithms for line tracking and obstacle avoidance, enhancing automation and decision-making.
